# 如何写一篇笔记

这是一篇**示例笔记**，用来展示本站支持的各种写法。看懂之后，你可以把它删掉，按同样格式写你自己的笔记。

## 基本格式

### 标题

用 `#`、`##`、`###` 表示不同级别的标题。

### 列表

- 无序列表
- 另一个条目
  - 嵌套条目

1. 有序列表
2. 第二项

### 引用

> 这是一段引用，适合写重点提示、注意事项。

### 表格

| 知识点 | 说明 |
| ------ | ---- |
| 概念 A | 描述 A |
| 概念 B | 描述 B |

### 代码块

```python
def hello(name):
    print(f"Hello, {name}!")
```

行内代码用反引号，比如 `print("hello")`。

## 数学公式

本站支持 LaTeX 数学公式：

**行内公式**：欧拉公式 $e^{i\pi} + 1 = 0$

**独立成行公式**：

$$
\int_{-\infty}^{+\infty} e^{-x^2} \, dx = \sqrt{\pi}
$$

**矩阵示例**：

$$
\begin{bmatrix}
a & b \\
c & d
\end{bmatrix}
$$

## 插入图片

把图片放进**和笔记同一个文件夹**里，然后用相对路径引用。语法如下（注意 `./` 后面要填真实存在的图片文件名，图片要先放进当前文件夹）：

```markdown
![图片说明](./图片名.png)
```

## 小贴士

- 每个学科建一个文件夹，笔记按主题命名。
- 一篇笔记 = 一个 `.md` 文件。
- 文件名建议用中文描述主题，方便搜索。
